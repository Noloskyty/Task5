# Task5

Тема 5: Задание 5: Нельзя вкладывать ListView или RecyclerView внутрь ScrollView с одинаковым направлением прокрутки, потому что:
ScrollView измеряет всю высоту списка сразу → все элементы создаются в памяти.
Теряется recycling (переиспользование View).
Возникают конфликты жестов прокрутки.
Сильно падает производительность.
Правильно: использовать только RecyclerView.
